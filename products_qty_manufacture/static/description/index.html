Products Qty Manufacture

Compute how many finished units can be manufactured from current BoM component stock.

Overview

This module extends products to calculate manufacturable quantity based on the selected Bill of Materials (BoM). It helps planners and warehouse teams decide what can be produced immediately with on-hand component stock.

Main Features

  • Adds a dedicated BoM field on product/product template for stock manufacturing calculation.
  • Adds To manufacture smart stat button with computed quantity.
  • Supports product and template forms (single-variant templates included).
  • Lets users open the selected BoM report directly from the smart button.
  • Optional context flag to include manufacturable quantity in forecasted stock.

How The Calculation Works

For each BoM component, the module computes: free_qty / required_qty. The smallest ratio (bottleneck component) defines how many BoM batches can be produced, then it is multiplied by the BoM production quantity.

Example: if BoM requires 1 board and 4 legs, and stock is 10 boards and 12 legs, the manufacturable quantity is 3 finished units.

Configuration

  1. Install Manufacturing and Inventory apps.
  2. Open a storable product that has a manufacturing BoM.
  3. Set BoM for compute manufacture stock on the product.
  4. Use the smart button to monitor To manufacture quantity.
